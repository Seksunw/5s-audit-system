## 1. เป้าหมาย

ตรวจเสร็จทั้งรอบแล้ว อยากกดปุ่มเดียวได้ผลการตรวจทั้ง dashboard เป็น PDF เพื่อ:
- เก็บเป็นเอกสารทางการ / ส่งผู้บริหาร
- **ฉีกใบเฉพาะพื้นที่ที่ตก ส่งให้เจ้าของพื้นที่นำไปแก้ไข**

---

## 2. แนวทางที่เลือก (หลังทำ mockup เทียบ 2 แบบ)

| แนวทาง | ผล | ตัดสิน |
|--------|-----|--------|
| 1. Print CSS + `window.print()` | ฟอนต์ไทยคม · select ได้ · ไฟล์เล็ก · ไม่มี dependency | ✅ **เลือก** |
| 2. html2canvas + jsPDF | กดปุ่มเดียวได้ไฟล์เลย แต่เป็นภาพ · ติด CORS รูป Supabase · ฟอนต์เพี้ยน | ❌ |

**กลไก:** สร้าง HTML รายงาน → เขียนลง `<iframe>` ซ่อน → รอฟอนต์+รูปโหลด → `iframe.print()`
→ ผู้ใช้เลือก "Save as PDF" (Print CSS ไม่ติด CORS รูปจาก Supabase)

## 3. โครงสร้างรายงาน

**หน้า 1 — สรุปภาพรวม** (พอดี 1 หน้า A4)
- KPI 3 ช่อง: คะแนนเฉลี่ย · พื้นที่ผ่านเกณฑ์ · จำนวนข้อที่ต้องปรับปรุง
- ตาราง Plant Ranking (ทุกโรงงาน)
- ตาราง Area Ranking (สูงสุด 3 / ต่ำสุด 3 ถ้าเกิน 6 พื้นที่)
- **ตารางรายชื่อผู้ตรวจประจำรอบ** (ใครตรวจพื้นที่ไหนบ้าง)

**หน้า 2 เป็นต้นไป — ใบแจ้งพื้นที่ต้องปรับปรุง** (1 พื้นที่ = 1 ใบ, เรียง Plant → Area)
- หัวใบ: โรงงาน / พื้นที่ / เจ้าของพื้นที่ / ผู้ตรวจ / วันที่ตรวจ / กำหนดแก้ไข
- แต่ละข้อที่ตก: หมวด + เลขข้อ · คำถาม · หมายเหตุผู้ตรวจ · **รูปถ่าย** · ตารางแผนแก้ไข (ให้เจ้าของกรอก)
- ท้ายใบ: เซ็น 3 ฝ่าย (ผู้ตรวจ / เจ้าของพื้นที่รับทราบ / ผู้จัดการอนุมัติ)

---

## 4. การตัดสินใจสำคัญ

- **เจ้าของพื้นที่:** ฐานข้อมูลไม่มี field นี้ → **เว้นบรรทัดว่างให้เซ็นเอง** (ไม่แก้ schema)
- **ผู้ตรวจ:** แต่ละพื้นที่คนตรวจต่างกัน → แสดงเป็นตารางรายชื่อผู้ตรวจครบทุกคน ต่อท้าย Area Ranking
- **กำหนดแก้ไข:** วันที่ตรวจ + 14 วัน (อัตโนมัติ)
- **รูปถ่าย:** ใส่รูปจาก Supabase (`safeImg` อนุญาตเฉพาะ http/https กัน XSS)
- **ภาษา:** ตาม `I18n.getLang()` (ไทย/อังกฤษ) — มี dict แยก `REPORT_STR` ไม่แตะ TRANSLATIONS หลัก

## 5. ไฟล์ที่แก้

### `dashboard.html`
- เพิ่มปุ่มไอคอน PDF บน top-nav → `onclick="exportDashboardPDF()"`

### `js/app.js`
- `getImprovementItems()` — เพิ่ม `criteria.sub_category` ใน select + field `Sub_Category` (เลขข้อ เช่น 30.1)
- `getDashboard()` — ดึง `profiles` เพิ่ม แล้วคืน `auditorRoster` (group ผู้ตรวจ → พื้นที่ที่รับผิดชอบ)
- `initDashboard()` — เก็บ `_lastDash` ไว้ให้ปุ่ม Export ใช้ ไม่ต้องยิง API ซ้ำ
- **ใหม่** `buildReportHTML(dash, impItems, opts)` — pure function ประกอบ HTML รายงานทั้งฉบับ (ทดสอบแยกได้)
- **ใหม่** `exportDashboardPDF()` — รวบรวมข้อมูล → iframe → print
- **ใหม่** `REPORT_STR` — ข้อความรายงาน th/en
